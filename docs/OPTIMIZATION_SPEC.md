# Optimization specification
Independently generate legal candidates for every legend; blind-discovery input excludes public decklists and derived features, meta mode uses verified event data separately. Include random/diverse starts, synergy graphs, card quantities, single/multi-card/package swaps, crossover, annealing, restarts, rune/battlefield/champion and sideboard search. Preserve diverse and historical elites. Adaptive screening allocates simulations by uncertainty; training scores are not adoption evidence. Frozen fresh seeds/opponents and multiplicity-aware promotion required.
Directed matchup objective: robust BO3 performance against multiple strong variants of one legend (mirror supported). Meta: weighted matchup win probability with documented representation/recency and field stress tests. Universal: mean, lower-tail, worst-case and consistency Pareto tradeoffs; weights configurable, validate by event outcomes. Qualification/top-cut/championship objectives use tournament probability, not just average win rate. Each legend receives independent budget and objective; no deliberate weakening. Co-evolve all populations with frozen historical and challenger pools; measure exploitability and stagnation. Record deck hashes, provenance, candidate lineage, seed partitions, agent/engine and uncertainty. Latest 348 packages are screening only.
