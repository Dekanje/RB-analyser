# Engine specification
Input: immutable ruleset, legal registered decks, agents, seed, match config. Output: explicit complete/draw/timeout/error status, game scores, winner, native receipts, replay, observability and hashes. Legal actions must be enumerated exactly, hidden data inaccessible to pilots, deterministic randomness replayable. Enforce card pool, domains, chosen champion, quantities, runes, battlefields and sideboard legality with native validation. Unknown effects fail closed. Never count invalid games as losses or quietly omit unsupported cards/legends. Separate simulation, selection, training and evaluation stores.
