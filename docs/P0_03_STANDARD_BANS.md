## Findings
- 22 official banned functional names (15 cards, seven battlefields) map uniquely by name/type to compiled IDs in registry SHA-256 d8102dd0930f466ce16c917035aff15eb21e347879800b08fa334b677f198b89. Explicit alias Dreaming Tree -> The Dreaming Tree (OGN-292/298); straight/curly apostrophes normalized.
- Native compiled flags contain 12 historical bans and omit the 10 additions: RAD-043/167 Riven, Broken Blade; OGN-077/298 Zhonya's Hourglass; SFD-048/221 Stellacorn Herder; OGN-194/298 Nocturne, Horrifying; OGN-195/298 Rhasa the Sunderer; OGN-026/298 Brynhir Thundersong; OGN-160/298 Dazzling Aurora; OGN-242/298 Baited Hook; SFD-207/221 Emperor's Dais; UNL-215/219 Star Spring. No extra native ban flags.
- optimize_58.py BANNED already contains all 22 names and key() handles the Dreaming Tree article alias. audit_full_pool_and_bans scans all rows, but not every execution path calls it. tournament_bo3_policy.py check_final_legality checks main, chosen champion and sideboard pool, not registered battlefields for bans. Native validator relies on older compiled flags. round_robin_58.py checks hashes/58 legends but has no independent current-format preflight. Thus no claim that all paths enforce the new ban list. Future centralized, explicit ruleset enforcement required; do not patch every historical campaign or globally mutate compiled flags without preserving historical format behavior.
- Independent local initial scan of archived 58 selected registrations (artifact 14823477036) and 580 structural variants (artifact 14859277678) found zero exact compiled banned-name rows. This is not full legality certification: legend name aliases and other print mappings need separate reconciliation. No new games or adoption.
