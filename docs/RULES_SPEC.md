# Rules specification
Use official dated core/tournament rules, card errata and rulings from https://riftbound.leagueoflegends.com/ or official PlayRiftbound channels; verify exact source URL/version before implementation. Record ruleset ID, effective date, sources and hashes, legality and card identity mapping. Audit timing, priority, triggers, replacement/continuous effects, cost, target, movement, combat, scoring, tokens, simultaneous actions, state invariants and victory. Build minimal positive/negative and cross-card fixtures per effect. Distinguish catalog registration, implemented effect and verified behavior. Unknown/changed rules quarantined; no silent approximation.
