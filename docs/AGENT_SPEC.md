# Gameplay agent specification
Random baseline for testing only; heuristic/tactical, ISMCTS, adaptive and learned policies. Agents receive only legal observations/actions, not full hidden state or future draws. Validate information-set sampling, opponent model, tactical sequencing, resource and scoring evaluation, deterministic budget and seeds. Compare controlled same-deck mirrored seats, multiple archetypes, equal-compute baselines and frozen holdouts; report paired uncertainty. Self-play logs observations, actions and outcomes; train lightweight policy/value first, evaluate against historical/challenger agents, promote only with supported improvement and rollback. See COMPETITIVE_VALIDATION_V1.md for existing benchmark.
