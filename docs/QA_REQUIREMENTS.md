# QA gates
Every change: focused positive/negative tests, deterministic replay where relevant, no unexplained failures. CI tier 1 smoke; tier 2 relevant regression; tier 3 full milestone validation; tier 4 local production campaigns. Rule tests include individual effects, triggers, cross-set interactions, property invariants, fuzz, official golden fixtures. Agent tests enforce information boundary, reproducible paired seats and held-out strength. Deck validity native and external, all legends represented; screening and independent promotion separate, multiplicity and uncertainty accounted for. Tournament fixtures in TOURNAMENT_SPEC.md. Fail closed on incomplete games; report draw/timeout/error separately. Record exact commands, test counts, CI URLs, engine/agent/rules/deck hashes, seeds and data splits. Green CI not exhaustive certification. Independent review before milestone acceptance.
